# Chrome 扩展安装说明

这个扩展是独立的本地优先论文标签库，不需要启动 `server.js`，也不需要本地 companion service。

## 安装扩展

1. 打开 Chrome，进入 `chrome://extensions`
2. 打开右上角的“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择这个目录：

```text
/Users/mayanna/Documents/Codex/2026-05-30/mac-qwen-api-key-llm-llm/extension
```

5. 建议把扩展固定到工具栏，之后点击图标即可快速添加论文。

## 数据保存位置

- 论文、标签、摘要和备注保存在插件的 IndexedDB 本地数据库中。
- 每日自动 JSON 备份会下载到 Chrome 默认下载目录；如果希望保存到桌面，可以把 Chrome 默认下载位置设为桌面。
- 模型设置和可选 API Key 保存在 `chrome.storage.local`。
- 不需要注册账号。
- 不需要启动 `127.0.0.1:5173`。
- 如果使用 LLM 功能，需要在“管理”里的模型设置页填写自己的 Qwen 或智谱 API Key。

## 导入 / 导出

在“管理”页面进入“模型设置”，底部有“数据导入 / 导出”：

- “本地 JSON 导入 Chrome”：可以选择旧本地服务的 `data/store.json`，也可以选择本插件之前导出的 JSON。
- “从 Chrome 导出本地 JSON”：会把当前 Chrome IndexedDB 里的论文和标签下载成本地 JSON 备份。
- 插件也会每日自动下载一份 JSON 备份到 Chrome 默认下载目录。
- API Key 不会随论文标签数据一起导出。

## 功能

- 自动读取当前标签页标题
- 尝试读取页面摘要、一级标题和选中文本
- 可以手动填写标题、摘要、对话记录/备注
- 标签框支持搜索已有标签，也可以直接输入新标签
- 未选择标签保存时会自动进入“待归类”系统标签
- 研究主题包可以按多个包含/排除标签实时聚合论文
- 点击“管理”打开完整插件管理页
- 管理页支持论文库、标签库、智能检索、标签合并审核、相似论文推荐和模型测试
