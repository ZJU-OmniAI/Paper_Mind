# Chrome 扩展安装说明

这个扩展用于在 Chrome 当前页面中快速添加论文到本地论文标签系统，不需要打开网页应用。

## 使用前

先在项目根目录启动本地服务：

```bash
npm run dev
```

本地服务地址是：

```text
http://127.0.0.1:5173
```

论文和标签数据仍然保存在项目里的：

```text
data/store.json
```

## 安装扩展

1. 打开 Chrome，进入 `chrome://extensions`
2. 打开右上角的“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择这个目录：

```text
/Users/mayanna/Documents/Codex/2026-05-30/mac-qwen-api-key-llm-llm/extension
```

5. 建议把扩展固定到工具栏，之后点击图标即可快速添加论文。

## 功能

- 自动读取当前标签页标题
- 尝试读取页面摘要、一级标题和选中文本
- 可以手动填写标题、摘要、对话记录/备注
- 标签框支持搜索已有标签，也可以直接输入新标签
- 保存后写入同一个本地论文标签库
- 点击“管理”可打开完整的本地 Web 管理系统
