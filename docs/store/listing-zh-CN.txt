读过一篇论文，后来却只记得：“好像是智能体的优化”“似乎关于 OPD 算法”“可能是某个团队出品”。标题和方法细节已经模糊，脑海中还留下几个概念。

Paper_Mind 让这些概念成为找回论文的入口：脑海中的概念 → 已有标签 → 收藏过的论文。

【先留下记忆，再找回论文】

1. 收藏时，用多个标签描述一篇论文
在论文页面打开插件，检查标题、作者、年份与发表出处，为研究方向、方法、团队等分别添加标签。优先复用已有标签和别名，再写下“一句话记住它”，保留属于你自己的理解。网页正文、图片和备注也可以一起剪藏。

2. 忘了标题，从还记得的概念开始
输入概念，匹配已有标签的名称、别名和说明。描述比较模糊时，可让你配置的模型帮助匹配已有标签。点击标签，查看关联论文；检索不会为了每个问题不断创建新标签。

3. 再补一条线索，逐步缩小范围
选中标签后，查看“还可以怎样缩小范围”的建议和剩余篇数。组合多个标签，在结果里直接读到“你当时记住的那句话”，确认是不是要找的那篇论文。

【让论文库保持清楚、好用】

• 标签说明：可由模型根据你给的标签、别名及关联论文内容生成，帮助理解标签含义与适用范围。
• 标签整理：支持别名、复用、冗余分析和需确认的 AI 合并建议；不设固定标签数量上限。
• 阅读进度：待读、在读、已读单独管理，不用状态标签挤占概念标签。
• 文献信息：读取页面学术元数据，也可查询 Semantic Scholar / Crossref 补齐空缺的作者、年份和出处，保存前可核对编辑。
• 主题包：组合包含与排除的标签，整理某个方向的论文。
• 数据备份：支持 JSON 导入、导出和每日定时备份；导入会替换当前论文库。
• 中英文界面：可切换语言，适合日常阅读和整理。

【AI 是可选项】

基础收藏、标签筛选、文本检索和阅读状态管理无需模型、无需 Paper_Mind 账号。

需要 AI 时，可以使用自己的 Claude Code、Codex 或 Chat Completions 兼容 API，也提供 Qwen、智谱 GLM、Kimi Code 和 DeepSeek 的设置入口。本机 CLI 支持选择模型与思考强度（effort），需要另外安装并登录相应 CLI、运行项目提供的桥接程序，并保持桥接运行。API 方式不需要桥接。模型访问权限及费用由所选服务决定。

【数据如何处理】

论文库保存在当前 Chrome 配置文件的扩展本地存储中，没有 Paper_Mind 云端论文库或分析埋点。元数据查询会向对应文献服务发送论文标识或标题；剪藏和预览可能访问来源网站。

启用模型后，相关查询、标签和论文文本会按功能发送给你选择的后端；保存论文也可能触发摘要翻译、相关论文推荐和自动标签说明。自动标签说明可在设置中关闭。本机 CLI 连接不等于离线推理。API Key 和桥接连接码保存在本机设置中，不进入论文库 JSON 备份。
